# CCA PDR Highlighter

- **Purpose**: Chrome extension that colors rows on `search.txcourts.gov` CCA case search by PDR stage, using the IACLS CCA database.
- **Local path**: `/Users/markbennett/github/chrome-extensions/cca-pdr-highlighter`
- **Server export**: `iacls:/home/ubuntu/github/cca/export_status_map.py` → `https://iacls.org/cca/status_map.json`
- **Last activity**: 2026-08-08

## Identity

Chrome MV3 extension (load unpacked). Content script on `search.txcourts.gov`; service worker fetches and caches `status_map.json` from iacls.org.

### Colors

| Stage key | Label | Color |
|-----------|--------|--------|
| `granted_pending` | Granted | yellow `#f5e663` |
| `submitted` | Submitted | green `#7dcea0` |
| `decided` | Decided | grey `#b0b0b0` |
| `refused` | Refused | red `#f1948a` |

Stage classification reuses the ladder in `export_timeline_data.py` (docket `PDR DISP` / submit / opinion events; does not treat extension grants as PDR grants).

## Now

Built and live. `https://iacls.org/cca/status_map.json` serves 15,426 cases (as of 2026-08-08). Extension package ready to load unpacked from this directory. Daily cron regenerates the map via `daily_update.py`.

## Known

- `status_map.json` is regenerated by `daily_update.py` after the timeline export.
- Extension caches the map for 6 hours in `chrome.storage.local`; popup can force refresh.
- Timeline page remains cohort-scoped; status map covers all `PD-*` cases in `cca.db`.
