# chrome-extensions

A monorepo of small, personal Chrome browser extensions, each in its own subdirectory (e.g. `mru-tabs`, `x-mass-blocker`, `PDF-zoomer-extension`, `high-contrast-extension`, `google-verbatim`, `fastmail-font-size`, `open-windows-in-tabs`). Each extension is self-contained with its own `manifest.json`, background/content scripts, and popup UI.

To run one locally: open `chrome://extensions`, enable Developer Mode, click 'Load unpacked', and select the desired extension's subdirectory (e.g. `mru-tabs/`).
